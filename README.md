# 🎬 Filmzone

A full-stack movie ticket booking backend system built using Node.js, Express, and MySQL. This project provides REST APIs for managing movies, user authentication, and ticket bookings.

---

## 🚀 Features

- 🎥 Browse movies with show timings
- 🔍 Search movies by title, genre, or theatre
- 👤 User registration & login system
- 🎟️ Book movie tickets
- 📜 View booking history
- 🗄️ MySQL database integration

---

## 🛠️ Tech Stack

- Node.js
- Express.js
- MySQL
- CORS
